# Employee Management Application

An Angular application for managing employee information.

## Features

- View employees
- Search employees
- Filter by department
- Add employee
- Edit employee
- Delete employee
- View employee details
- Form validation
- Angular routing

## Tech Stack

- Angular 22
- TypeScript
- Reactive Forms
- Angular Router
- Signals
- HTML/CSS

## Run Locally

```bash
npm install
ng serve
